# Historical plans

Everything in this directory is a **record of past decisions**, not current design. Many describe
code removed by the 2026-10 core redesign (`redesign_core_engine.md`): IRLM, PARTIAL/SELECTIVE
reorthogonalization and the PRO machinery, `ea16.py`, the Chebyshev filter, the scipy ARPACK
fallback, `dc_frozen`, the separate array Lanczos kernel. For the current layout read
`doc/architecture_overview.md`.
